# Nascente

O ritual de cuidado da pele: fotografas os teus frascos e a Nascente diz quais usar, de manhã ou à noite, por que ordem, como aplicar e o que não misturar.

- Abre em https://danielgog7.github.io/nascente/ e instala no telemóvel ("Instalar app" no Chrome).
- Motor local (funciona sem IA e sem internet): ordem dos passos, ativos incompatíveis, noites de retinoide / esfoliação / recuperação, frascos repetidos em fila.
- O Mestre (IA opcional, Gemini) lê os rótulos pela foto, revê os frascos, comenta os registos da pele e responde a perguntas. Usa a chave gratuita de cada utilizador, guardada só no dispositivo.
- Dados no dispositivo de cada pessoa (fotos em IndexedDB). Sincronização opcional com um repositório GitHub privado de cada um.
- Os conselhos não substituem um dermatologista.
